# Handoff

Version 0.9.3 is the current Apple Silicon build. The practice library, personal playlists, review, recoverable Trash, and managed Rekordbox XML are the supported workflows. See the README for setup and the import checklist for the manual Rekordbox step.

The repository uses synthetic fixtures. Personal library catalogs, exports, research, recovery history, and deployment notes belong outside the source tree. Third-party notices are regenerated by the build and included in the packaged app.

The first source release was checked on Apple Silicon macOS on November 10, 2026:

- `npm run format:check`, `npm run typecheck`, and `npm run build` passed.
- `npm test` passed all 168 integration tests with normal macOS audio and Trash access.
- `npm run package` and `npm run smoke` passed with an isolated profile and 18 generated files.
- The source restyle preserved compiled behavior. The renderer changes only regroup adjacent JSX text; the text itself is unchanged.

Direct compatibility with a user's live Rekordbox collection and provider-specific macOS permissions need separate hands-on checks.
